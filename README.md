# homebrew-tap

## MenuSprite

Native macOS menu-bar monitoring with customizable CPU, RAM, Power and paired
readouts. Public preview for Apple Silicon Macs on macOS 26+.

```sh
brew install --cask prerakgada/tap/menusprite
```

[Downloads and release notes](https://github.com/PrerakGada/menusprite-releases/releases).
The app is Developer ID-signed and notarized. The preview excludes privileged
battery charging and closed-lid controls.
